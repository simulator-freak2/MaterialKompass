# Passkey-Webbrücke

`passkeys.js` ist die lokal ausgelieferte Browserbrücke des Flutter-Pakets
`passkeys` 2.22.3. Sie stammt aus dem offiziellen Release-Bundle 2.4.0:

https://github.com/corbado/flutter-passkeys/releases/download/2.4.0/bundle.js

SHA-256 der eingecheckten Datei:

```text
DD06B08556F161F0518D701FD0A1BF9B3F5144E2E0D6E1F5C3CAC81742C0BE49
```

Beim Aktualisieren des Flutter-Pakets muss die in dessen Dokumentation genannte
Bundle-Version bewusst geprüft, heruntergeladen und der neue Hash hier dokumentiert
werden. Die Datei wird selbst gehostet, damit die Anmeldeseite keine externe
JavaScript-Laufzeitabhängigkeit besitzt.
